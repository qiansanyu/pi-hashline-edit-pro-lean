### replace  (998 B)
D  Replace whole anchored lines. For part of a line, use replace_match.
S  Replace anchored lines
G  replace: one line uses the same anchor twice. A pure deletion checks only the boundary lines and removes the interior as it stands.
G  edit tools: the payload is written exactly as received, without anchor prefixes, and the tool never decodes an escape — a real line break is a line break. [H_LITERAL_ESCAPE] counts the literal characters that landed; go by that count, not by a backslash-doubling rule. A trailing line break sets the newline of the last line written instead of adding a blank line; a lone newline writes one blank line.
G  edit tools: same-file calls in one message form one batch — send the ones whose anchors you already hold together, and an edit that needs a previous result's anchors waits for the next turn; one undo reverts all.

P  5-char anchor of the LAST line to remove.
P  The exact text to write in place of the removed range. "" deletes the range.

P  5-char anchor of the FIRST line of the range searched.
P  5-char anchor of the LAST line of the range searched; same as `replace_from` for a single line.
